# 버추얼 벨라 가이드페이지

디스코드 보탐·레이드 출석봇 **벨라꼬붕**의 웹 관리 페이지입니다. (GitHub Pages)

- 디스코드 계정으로 로그인 → 봇 주인 · 서버 주인 · 관리판에서 지정된 관리자만 자기 서버를 관리할 수 있어요.
- **보스**: 표시 이름 · 리젠/일정 · 별명 수정, 제외, 추가·삭제
- **설정**: 모집·알림 시점, 채널, 입장 인사 채널
- **레기온**: 이번 주 일요일 길드전(엘리시움 / 공성·요새전) 선택, 전투 예약·취소
- **출석**: 월별 보스레이드·레기온 참여 순위, 기록별 명단 수정, CSV 내보내기
- **관리자**: 관리자 지정·해제 (봇 주인·서버 주인)

이 저장소에는 웹페이지 파일만 있습니다. 데이터는 Supabase에 있고, 보안 규칙(RLS)이 접근을 막습니다.
`config.js`의 Supabase 주소·publishable 키는 원래 공개용 값입니다.
