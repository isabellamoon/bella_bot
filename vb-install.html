버추얼 벨라 설치 안내

신뢰 등록 · 백신 예외 설정 · 되돌리기

1. 폴더 준비

  • 받은 VirtualBella.exe를 폴더 하나에 넣어 주세요. 예: C:\VirtualBella
  • 다운로드 폴더나 바탕화면보다는 전용 폴더가 좋아요. 아래 백신 예외도 이 폴더 하나만 지정하면 돼요.

2. 이 PC에 신뢰 등록 (선택)

윈도우가 버추얼 벨라를 "알 수 없는 게시자"로 보지 않도록, 이 PC에서만 통하는 서명을 해 주는 배치파일이에요. 아래 내용을 읽고 동의하면 받을 수 있어요.

무엇을 하나요

  1. 이 PC에서만 쓰는 코드 서명 전용 인증서를 새로 만듭니다. 인증서는 PC마다 따로 만들어지고, 다른 사람과 공유되는 인증서나 키는 없습니다.
  2. 같은 폴더의 VirtualBella.exe에 그 인증서로 서명합니다.
  3. 인증서의 공개 부분을 이 PC의 "신뢰할 수 있는 루트 인증 기관"과 "신뢰할 수 있는 게시자"에 등록합니다.
  4. 서명에 쓴 키는 곧바로 삭제합니다. 그래서 이후에는 이 PC에서도, 다른 누구도 이 인증서로 새 프로그램에 서명할 수 없습니다.
  5. 인터넷에서 받은 파일 표시를 지우고 버추얼 벨라를 실행합니다.

알아 두실 점

  • 관리자 권한이 필요합니다. 실행하면 윈도우가 권한을 묻습니다.
  • 인증서는 "코드 서명" 용도로만 만들어집니다. 웹사이트 인증서처럼 쓰일 수 없습니다.
  • 이 작업은 윈도우의 인증서 목록에 항목을 추가하는 것으로, 이 PC에만 영향을 줍니다. 백신을 끄거나 윈도우 보안 설정을 바꾸지 않습니다.
  • 백신이 버추얼 벨라를 막는 문제는 이것으로 해결되지 않을 수 있습니다. 그럴 땐 아래 3번(백신 예외)을 따라 주세요.
  • VirtualBella.exe를 새 버전으로 바꾸면 bella_cert의 [1]을 한 번 더 실행해야 합니다. 이전 인증서는 그때 자동으로 정리됩니다.
  • 언제든 bella_cert의 [2] 신뢰 해제로 등록 전 상태로 되돌릴 수 있습니다.
  • bella_cert.bat는 메모장으로 열어 내용을 직접 확인할 수 있습니다. 위에 적은 일 외에는 하지 않습니다.
  • 설치와 사용은 본인의 선택이며, 윈도우 버전이나 PC 환경에 따라 동작하지 않을 수 있습니다.
bella_cert 받기 (zip)

사용 방법

  1. 받은 zip 파일을 우클릭 → 속성 → 아래쪽 차단 해제 체크 → 확인. (이렇게 하면 실행할 때 파란 경고창이 덜 떠요.)
  2. 압축을 풀어 bella_cert.bat를 VirtualBella.exe와 같은 폴더에 넣어 주세요.
  3. bella_cert.bat 더블클릭 → 권한 요청에서 예 → 메뉴에서 1 입력 후 Enter.
  4. "완료!"가 뜨면 버추얼 벨라가 자동으로 켜져요. 다음부터는 VirtualBella.exe만 실행하면 돼요.
  5. 메뉴 3(상태 확인)으로 등록 여부와 서명 상태를 볼 수 있어요.

파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러 주세요.

3. 백신 예외 설정

버추얼 벨라는 게임 화면을 읽고 단축키를 감지하기 때문에, 백신이 의심스러운 프로그램으로 오해할 수 있어요. 막히거나 파일이 사라지면 버추얼 벨라 폴더 하나만 예외로 넣어 주세요.

C드라이브 전체, Windows, Program Files, 다운로드 폴더처럼 넓은 곳은 예외로 넣지 마세요.

백신 프로그램 버전에 따라 메뉴 이름이 조금 다를 수 있어요.

Windows 보안 (Microsoft Defender) — 기본 백신
  1. 시작 → 설정 → 개인 정보 및 보안(윈10: 업데이트 및 보안) → Windows 보안 → 바이러스 및 위협 방지
  2. "바이러스 및 위협 방지 설정" 아래 설정 관리
  3. 아래로 내려 제외 → 제외 사항 추가 또는 제거
  4. 제외 사항 추가 → 폴더 → 버추얼 벨라 폴더 선택

이미 파일이 지워졌다면: 바이러스 및 위협 방지 → 보호 기록에서 해당 항목 → 작업 → 복원.

V3 Lite (안랩)
  1. V3 Lite 실행 → 왼쪽 아래 환경 설정
  2. 검사 예외 설정 → 검사 예외 사용 켜기
  3. 검사 예외 대상에서 폴더 추가 → 버추얼 벨라 폴더 선택 → 확인
알약 (이스트시큐리티)
  1. 알약 실행 → 오른쪽 위 환경설정
  2. 왼쪽 메뉴 탐지 제외 (버전에 따라 "검사 예외")
  3. 추가 → 버추얼 벨라 폴더 선택 → 실시간 감시와 수동 검사 모두 제외로 설정 → 확인
Avast / AVG
  1. Avast 실행 → 메뉴 → 설정
  2. 일반 → 예외 → 예외 추가
  3. 버추얼 벨라 폴더 경로 입력(예: C:\VirtualBella\*) → 예외 추가

4. 되돌리기 · 지우기

  • 신뢰 등록 해제: bella_cert.bat 실행 → 메뉴에서 2.
  • 백신 예외: 위 3번 화면에서 넣은 폴더를 다시 지우면 돼요.
  • 버추얼 벨라 삭제: 버추얼 벨라를 끈 뒤 폴더째 지우면 끝이에요.
